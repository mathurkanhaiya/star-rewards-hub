3. New PVP Games (Bot-Only)
All PVP games will be available only through the bot (not in mini app for now).
Core Mechanics (Same for all games)
•  /dice <amount> (minimum 100 ADR)
	•  Bot creates a public challenge: 🎲 DEADLOX has challenged 100 ADR! Anyone can accept with /dice 100
	•  When someone accepts: 🤼 Match-up: DEADLOX vs KNIGHT
	•  Bot rolls: 🎲 DEADLOX rolled 4 🎲 KNIGHT rolled 2
	•  Result: 🏆 DEADLOX wins 198 ADR! (amount × 2 minus small house fee) Or if tie: “It’s a tie! Both get refund.”
•  House fee: Small percentage (e.g., 2-5%) deducted from the pot. Configurable in admin settings.
Additional Games (Same Logic)
•  /dart <amount>
•  /football <amount>
•  /bowling <amount>
Each uses its own emoji/theme but identical flow:
1.  Challenge creation
2.  Accept by same command + amount
3.  Bot “rolls” (random outcome 1-6 or similar)
4.  Declare winner + payout (or tie refund)
Implementation Notes:
•  Use Telegram’s built-in Dice emoji where possible for visual appeal (🎲, 🎯 for dart, ⚽ for football, 🎳 for bowling).
•  Store active challenges in database with timeout (e.g., 5-10 minutes to accept).
•  Handle concurrency (only one active challenge per user at a time).
•  Log all games for fairness/audit
